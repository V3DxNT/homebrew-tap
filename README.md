## 🍺 Install Homebrew

If you don't already have Homebrew installed on your machine, you will need it to use this tap. You can install it by running the following command in your terminal:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```
*(Learn more at the official [Homebrew website](https://brew.sh))*

## 📦 Available Tools

Below are the tools currently available in this tap. 

### 🌟 Ray

Ray is a fast, cross-platform CLI designed for deep codebase introspection. 
👉 **[Check out the Ray repository on GitHub](https://github.com/V3DxNT/ray)**

#### How to Install Ray

First, add this tap to your Homebrew configuration:

```bash
brew tap V3DxNT/tap
```

Then, install the `ray` package:

```bash
brew install ray
```

Verify the installation was successful by running:

```bash
ray --help
```
